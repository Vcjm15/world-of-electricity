# 电的世界 · 从一颗电荷到一座电网

> 一本可以在浏览器里直接打开、能点、能拖、能看的互动电磁学读本。
> 零基础友好，不需要会解方程。

🔗 **在线预览：<https://vcjm15.github.io/world-of-electricity/>**

---

## 这是什么

大多数人学电学，都是从公式开始的，于是很快就放弃了。

这份读本反过来走：**先从你手上那点静电、墙上那个插座、口袋里那部手机出发，一层层往回拆，一直拆到"电子"这一层。** 看到最后你会发现，家里每一件带电的东西，其实都在讲同一件事。

全书用生活类比建立直觉，只在真正必要的地方引入公式（一共只有三个），其余全靠画面和可以亲手操作的实验。

## 九个动手实验

页面里嵌了九个可以真正拖动的实验台——这是这份读本和普通电子书最大的区别：

| 实验 | 在哪儿 | 能玩什么 |
|---|---|---|
| 摩擦起电 | 第 1 章 | 点「摩擦气球」给它充负电，看小纸屑被吸起来 |
| 欧姆定律 | 第 2 章 | 拖电压和电阻两个滑块，灯泡亮度、电流快慢实时变化 |
| 磁场方向 | 第 3 章 | 拖动小磁针，看它怎么顺着磁力线转；一键翻转电流方向 |
| 电磁铁 | 第 3 章 | 调电流看磁场强弱，磁极瞬间左右对调，回形针被吸起又掉落 |
| 电磁感应 | 第 3 章 | 按住磁铁左右拖，看电流计指针偏转；松手停住指针立刻归零 |
| 电动机 | 第 3 章 | 看线圈怎么被磁场推着转，换向器每半圈翻一次电流 |
| 电磁波谱 | 第 5 章 | 一个滑块从无线电波一路滑到伽马射线，波长实时变化 |
| 调制 | 第 5 章 | 一键切换 AM / FM，看信息怎么「骑」到载波上 |
| 变压器 | 第 6 章 | 拖匝数比，看升压降压，理解为什么电网要用交流 |

## 技术说明

- **纯前端，零依赖**：没有框架、没有构建步骤、没有 npm。整个页面就是两个 HTML 文件。
- **单文件自包含**：CSS 和 JavaScript 全部内联在 HTML 里，复制一个文件就能独立运行。
- **动画用原生 Canvas**：所有实验台都是手写 Canvas 绘图 + 原生 JS，没有引入任何图形库。
- **离线可用**：断网也能正常打开。字体走 Google Fonts，加载不到时会优雅降级到系统字体，不影响阅读。
- **响应式**：手机上会自动把左侧目录收成顶部下拉框。
- **无障碍**：支持键盘操作、尊重系统的「减少动态效果」设置。
